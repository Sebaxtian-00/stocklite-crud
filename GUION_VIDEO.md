# Guion para el video — StockLite CRUD

**Autor:** Andres Sebaxtian Vargas Bermeo  
**Duración objetivo:** 7 a 9 minutos (máximo 10).

## Antes de grabar
1. Abre StockLite en el navegador.
2. Abre los archivos del proyecto y PROMPTS.md en Visual Studio Code.
3. Abre ChatGPT en la conversación donde trabajaste el proyecto.
4. Prueba antes las operaciones para no perder tiempo durante la grabación.

## 0:00–0:40 | Presentación
Di tu nombre, programa académico, seminario y presenta StockLite como una aplicación web CRUD para administrar un inventario.

## 0:40–1:40 | Proceso con IA
Muestra la conversación real con ChatGPT. Explica cómo pediste ayuda para definir requisitos, elegir tecnologías, construir la interfaz y programar las funciones. Aclara qué partes revisaste y probaste.

## 1:40–2:30 | Tecnologías y código
Muestra index.html. Explica brevemente que HTML estructura la página, CSS define la presentación y JavaScript implementa la lógica. Los datos se guardan en LocalStorage.

## 2:30–3:15 | READ — Consultar
Muestra la tabla, escribe una búsqueda y selecciona una categoría. Explica que los productos pueden consultarse sin recargar la página.

## 3:15–4:20 | CREATE — Crear
Pulsa Agregar producto. Registra por ejemplo: Audífonos USB, categoría Tecnología, cantidad 8 y precio 65000. Guarda y señala el nuevo registro y los indicadores actualizados.

## 4:20–5:30 | UPDATE — Actualizar
Edita el producto recién agregado. Cambia la cantidad de 8 a 3 y guarda. Explica que el registro existente se actualiza y cambia a estado de stock bajo.

## 5:30–6:20 | DELETE — Eliminar
Pulsa Eliminar en el producto de prueba. Lee la confirmación y acepta. Muestra que el registro desaparece de la tabla.

## 6:20–7:10 | Validaciones y persistencia
Intenta guardar el formulario con un campo obligatorio vacío o cantidad decimal. Muestra el mensaje de validación. Luego recarga la página y explica que LocalStorage conserva los cambios dentro del mismo navegador.

## 7:10–8:00 | Repositorio y cierre
Muestra GitHub, README.md y PROMPTS.md. Menciona como mejora futura la incorporación de un backend y una base de datos compartida. Finaliza agradeciendo.
